中学生数学学习助手 · 网页前端（Streamlit）。接入成员1 规则模块 v1.3.1，供成员5 进行页面验收与功能测试演示。

> 本包是**前端原型**，不是生产级网页应用：无数据库、无真实登录、无真实数学批改/OCR、题库为演示数据。规则计算接通成员1 模块；其余模拟/待接入项见《页面与接口对应表.md》。
> v0.4 按组长《v0.3ui修改》14 条建议重构前端 UI 与流程：进度与回顾入口、后台信息/日志收进右上角 ⋮ 菜单、回车提交、按钮顺序与答案条件出现、对错反馈、离开后 3 秒自动返回首页、判断页选项按完成情况消去、今日完成态、复测收口（保存按钮提交后出现、结算区收起、剩余题数提示）。

## 三、启动说明

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 在本目录启动：

   ```bash
   streamlit run app.py
   ```

3. 浏览器打开终端显示的本地地址（默认 `http://localhost:8501`）。

- **匿名访问**：原型无需登录，进入即为演示访客；真实身份鉴权待成员3 接入。

  ```bash

  ```

- 无头界面回归（可选，验证各阶段渲染无异常）：

  ```bash
  python3 apptest_check.py
  ```

## 四、演示流程建议（供成员5 验收走查）

1. 首页显示当前进度（已完成题数、答对数）；可「进入预习自学」看例题，或「直接开始测试」进入诊断；有历史作答时出现「查看已学过的知识（回顾）」。
2. 右上角 **⋮ 更多** 菜单：学习状态总览（掌握等级/分族/复测计划/证据条数）、整体回顾、错题回顾、操作日志、重置演示；后台判断信息不再直接展示在首页。
3. 例题页可做即时练习、稍后测试（提示 3 秒后自动返回首页），或跳过练习进入独立验证。
4. 作答区：输入框内回车即可提交；按钮顺序为 提交 / 请求提示 / 暂时不会 / 查看完整答案（查看答案需先请求过一次提示）；提交后在输入框下方显示 ✓正确 / ✗错误 / ○暂时不会；答对后出现「下一题」，错误时维持提交/提示/不会按钮。
5. 诊断 / 独立验证 / 迁移题完成后回到掌握判断页；已做过的补学、重做诊断等选项会从「下一步」中消去；还有未做的验证题时显示「做新题独立验证」。
6. 补足必测族新题后进入「独立验证」（两道新题）；达标后创建次日复测计划，做情境迁移题。
7. 复测：每题显示剩余题数；保存按钮在提交作答后才出现，作答指标在复测中隐去；「本轮结算 / 结束与异常」默认收起，展开后可勾选主动结束本轮或技术异常。暂缓（pending）时计划与当前题目证据保留、不计入已结算列表，恢复后可同任务重试且仅结算一次。
8. 今日全部完成后，判断页不再显示「下一步」，直接显示「今日学习已完成」，可点按钮返回主界面。
9. 照片流程：上传照片后预览原图、查看模拟原始转录，可逐行修正并确认转录后用于作答；确认后再修改会撤销确认、需重新确认；也可重新拍摄补拍。未确认的照片不进入有效提交，仍可独立用文字作答；OCR 识别本身待成员4。

## 五、已实现功能（原型内可操作）

- 两种学习入口（预习自学 / 直接测试）与「稍后测试」状态；首页实时显示已完成题数与答对数；
- 右上角 ⋮ 菜单收纳：学习状态总览、整体回顾、错题回顾、操作日志、重置演示；后台掌握判断信息不再直接展示在首页；
- 整体回顾列出所有做过题目及作答情况；错题回顾收录首答出错、最终出错、提示/看答案后才作对的题；
- 作答区回车提交（`st.form`）；按钮顺序为 提交 / 请求提示 / 暂时不会 / 查看完整答案；查看答案需先请求过至少一次提示；
- 提交后输入框下方以 ✓/✗/○ 与颜色文案反馈对错；答对后出现「下一题」，错误时维持提交/提示/不会按钮；
- 离开练习或稍后测试时提示「3 秒后返回初始页面」并自动跳回首页，首页同步进度；
- 判断页选项按完成情况消去：补学练习、重做诊断做过后不再显示；还有未做验证题时才显示新题验证；今日全部完成后显示「今日学习已完成」并可返回主界面；
- 复测收口：剩余题数提示；保存按钮在提交作答后出现；复测作答指标隐去；结算/结束/异常区默认收起；
- 文字作答、首答保留、改答历史留痕；每题作答框独立，新题不带入旧解答；
- 三级分级提示、完整答案查看与留痕；提示正文从会话事件重建，刷新或交互后仍可读，不重复记录帮助；
- 整题结果与目标步骤结果分别展示、分族证据与掌握依据（`assess`）；
- 独立验证准备校验（`prepare_validation`）；
- 复测计划创建、两道复测题、主动结束本轮、技术异常暂缓；未凑齐两题也可主动结束或暂缓；
- 暂缓（pending）时保留当前任务与已存证据，不发布到已结算列表，可同任务重试且仅结算一次；
- 六档间隔与失败次日重启、历史保留（规则层）；演示复测池 16 道（六档 12 道 + 失败重启备用）；
- 照片上传、原图预览、原始转录展示、逐行核对/修正、确认转录与补拍的前端状态流转；照片模式提交使用确认版本，留存原始转录/确认版本/修改来源；确认后再编辑自动撤销确认；未确认照片按文字作答处理；补拍与同题重开会自动清理旧控件状态（OCR 识别待成员4）。

## 六、已知问题与未接入边界

- **无持久化**：会话、证据、计划仅存浏览器内存，刷新即重置；数据库、鉴权、幂等、并发事务由成员3 实现。应用页顶部已有「刷新会重置」的可见提示，属当前原型的预期行为，不是缺陷。
- **判分为演示模拟**：`service.judge()` 只提取作答数字与参考答案宽松比对，不是真实数学批改；目标步骤判定当前为整题映射演示。真实判分（成员4）接入时须沿用 `correct/wrong/no_attempt/pending` 四值。
- **字段一致性**：题号、作答、帮助记录的字段名以成员1 `learning_rules.py` 为准，逐字段对照见《页面与接口对应表.md》第四节；成员3 若用不同命名需给出映射。
- **题库为演示数据**：题目、答案、提示文案均非正式题库；正式题库由成员4配合提供，成员5审核标准答案与目标步骤，成员2不单独审核教学内容。
- **OCR/转录识别待成员4**：前端已做好上传、转录核对、修正与补拍的状态流转，但原始识别结果为模拟文本；图片受控存储待成员3。
- **无后端 HTTP 接口**：当前本地直调规则函数；切换点已收口到 `api_client.py`——配好 `BACKEND_BASE_URL` 即改走 HTTP，未配则保持本地规则（当前状态）。接口契约与待补清单见对应表第二节。
- **日期为演示推进**：复测到期通过「模拟推进到到期日」按钮跳转，非真实时间流逝。
- **对错边框颜色受限**：Streamlit 文本输入框不直接支持自定义边框颜色；当前以输入框下方 ✓/✗/○ 标记与 success/error/info 文案行呈现对错，未改输入框边框配色。
- 规则参数（必测族、每族题数、稳定门槛等）为初版配置，未经教学效果验证。
